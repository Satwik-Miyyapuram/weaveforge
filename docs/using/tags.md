# Tags

A tag is a short word that you attach to a note or a paper so you can find
everything about one topic later. In WeaveForge you make a tag by typing a hash
sign (#) and a word in the text, so there is nothing to set up first.

Tags let you pull together notes and papers that never link to each other. A
paper about MRI and a note about scanner noise can share the same tag, and a
filter on that tag shows both.

## Add a tag

1. Open the note, or the note on a paper, and click into its text.
2. Type # and a word, for example #mri-study.
3. Keep typing or move on. The tag ends at the first space or punctuation mark.
4. On a paper, the tag appears once the note saves. There is no separate add
   button for tags on a paper, so the note is the only place to add one.

## Find everything with a tag

1. On the Notes screen, open the **Tags** filter beside the list and pick one or
   more tags. The **Tags** filter appears once a note has a tag.
2. On the Papers screen, open the **Tags** filter beside the list and pick one or
   more tags.
3. Each tag in the filter shows with its hash sign, so #mri-study is listed as
   that.

Other places where tags show:

- The search box matches a hashtag word, so a search for the tag finds the notes
  and papers that carry it.
- The graph shows each tag as its own square node. You can also limit the graph
  to the items that have chosen tags.
- The dashboard has a card that lists your top tags.

## Remove a tag

Removing a tag deletes its hash sign and word from the text. The tag goes away
everywhere it appeared in that note.

- **On a note:** open the note in its read view. Each tag is shown as a chip with
  a remove control. Use it to take the tag out.
- **On a paper:** open the paper note in edit mode. Each tag is shown as a chip
  with a remove control. Use it to take the tag out, and the text in the open
  editor changes at once.

## Tags on papers and notes

- A paper shows its tags in its details, on a row labelled **Tags**. The tags
  come only from the note on that paper.
- A note shows its tags in its details, on a row labelled **Tags**.

## Good to know

- Tags are lowercase. #MRI and #mri are the same tag.
- A tag can use letters from any language, numbers, underscores and hyphens.
  Any other character ends it.
- A space, a full stop, a comma or an apostrophe ends the tag. Write #deep-learning,
  not #deep.learning, if you want both words.
- A hash sign followed by a space is not a tag. A line that starts with a
  heading mark and a space is not a tag either.
- A number can be a tag, so #2026 works.
- If the same tag appears more than once, it counts once in lists and filters.

## Stuck?

*My tag does not show up. Why?*
Check that the word follows the hash sign with no space in between. On a paper,
wait for the note to save, because the tag appears after that.

*Why does #MRI show as the same tag as #mri?*
WeaveForge compares tags in lowercase. Your text stays as you typed it, but
#MRI and #mri count as one tag in lists and filters.

*Why was my tag cut short?*
A space or punctuation mark ends a tag. Join the words with a hyphen or an
underscore instead.

*Can I add a tag to a paper from its details?*
No. A paper has no separate add control for tags. Write the #tag in the note on
the paper, and the tag comes from there.
