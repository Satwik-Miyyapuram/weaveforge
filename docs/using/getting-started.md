# Getting started

In about 10 minutes you make a project, add a paper to it, and write your first
note that cites it. You need the [desktop app](desktop.md) installed, or the
web app open in a browser.

## 1. Make a project

A project holds the papers, notes and experiments of one piece of work, such as
a thesis. See [Projects and workspaces](workspaces.md) for more.

1. Open **Projects**.
2. Select **New project**.
3. In **Name**, type a name, for example `Latent Spaces Thesis`.
4. Confirm. The new project opens, and everything you add from now on goes into it.

## 2. Add a paper

1. Open **Papers**.
2. Select **Add paper**.
3. Under **…or import from**, choose **DOI**.
4. Paste a DOI, for example `10.1145/3592979`. A `doi.org` link works too.
5. Select **Add paper**. The title, authors and year are filled in for you, and
   the paper appears in the list.

You can also add a paper from an arXiv id, a URL or a Zotero key; drop a PDF on
the form (**…or add from a PDF**); or import a whole BibTeX file
(**…or import a BibTeX file**). Dropping PDFs on the **Papers** list works too.

## 3. Write a note

1. Open **Notes**.
2. Select **New note**. An empty note opens in the editor.
3. Type a title on the first line, then write. Notes are Markdown: `# Heading`,
   `**bold**`, `- list`.
4. Your note saves as you type.

## 4. Find anything again

1. Press **Ctrl+K** (**⌘K** on a Mac). The palette opens with
   **Jump to paper, note, or section…**.
2. Type part of a paper title or a note name.
3. Press **Enter** to open the top result, or **Esc** to close.

**Ctrl+Shift+P** (**⌘⇧P**) opens the same palette with commands instead. See
[Search](search.md).
